Compile `hello.c`

On Linux

```sh
gcc hello.c -o hello
```

On Windows, in a `Developer Command Prompt for VS` with Microsoft compiler

```default
cl hello.c /Fe: hello
```

or with `clang` compiler

```default
clang-cl hello.c -o hello
```
